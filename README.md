# Tracking-Study-Topics

เว็บตรวจเช็คหัวข้อการอ่านหนังสือ ไฟล์เดียว (`index.html`) เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## ฟีเจอร์
- เพิ่ม/ลบ/เปลี่ยนชื่อวิชา (ไม่จำกัดจำนวน)
- เพิ่ม/ลบ/เปลี่ยนชื่อหัวข้อย่อย (ไม่จำกัดจำนวน)
- สถานะของแต่ละหัวข้อผ่าน Pipeline ที่แก้ไขได้ (ค่าเริ่มต้น: ยังไม่อ่าน → อ่านแล้ว → รอทำควิซ → ทำควิซแล้ว)
- แถบความคืบหน้า % รายวิชาและภาพรวม, ตัวกรองสถานะ, โหมดมืด
- สำรอง/นำเข้าข้อมูลเป็น JSON

## การเก็บข้อมูล
ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ ควรกดสำรองข้อมูลเป็นระยะ

## ใช้งานผ่าน GitHub Pages
Settings → Pages → เลือก branch `main` และโฟลเดอร์ `/ (root)`
