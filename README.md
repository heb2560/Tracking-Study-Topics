# Tracking-Study-Topics

เว็บตรวจเช็คหัวข้อการอ่านหนังสือ ไฟล์เดียว (`index.html`) เปิดในเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไร

## โครงสร้าง
`วิชา → หัวข้อย่อย → หัวข้อย่อย 2` เพิ่ม/ลบ/เปลี่ยนชื่อได้ทุกระดับ ไม่จำกัดจำนวน

## ฟีเจอร์
- **Pipeline** ผูกกับหัวข้อย่อย 2 (ค่าเริ่มต้น: ยังไม่อ่าน → อ่านแล้ว → รอทำควิซ → ทำควิซแล้ว) แก้ชื่อ สี ลำดับ และเพิ่ม/ลบขั้นตอนได้
- **Deadline** ใส่ที่หัวข้อย่อย 2 (วันที่อย่างเดียว) งานที่ถึงกำหนดภายใน N วัน (ค่าเริ่มต้น 3) จะไฮไลต์พร้อมป้าย เช่น `⏰ วันนี้`, `⏰ อีก 3 วัน` งานที่เลยกำหนดแล้วยังไม่เสร็จจะเป็นสีแดง `⚠ เลยมา N วัน` งานที่อยู่ในขั้นตอนที่นับเป็นเสร็จจะไม่ถูกไฮไลต์
- กล่อง "งานใกล้กำหนด" ในหน้าภาพรวม ปรับจำนวนวันเตือนล่วงหน้าได้ และตัวกรอง "ใกล้กำหนด" ในหน้าหัวข้อ (ใช้ร่วมกับตัวกรองสถานะได้)
- แถบความคืบหน้า % รายหัวข้อย่อย รายวิชา และภาพรวม คำนวณจากหัวข้อย่อย 2 ที่อยู่ในขั้นตอนที่นับเป็นเสร็จ
- **จับเวลา Pomodoro** (แท็บ "จับเวลา") ตั้งช่วงอ่าน พักสั้น พักยาว และพักยาวทุกกี่รอบได้ (ค่าเริ่มต้น 25/5/15/4) เมื่อหมดเวลาจะ**ไม่เข้าช่วงถัดไปเอง** แต่ขึ้นแบนเนอร์ที่ด้านบนของทุกหน้าพร้อมปุ่ม "เข้าช่วงพัก" / "เริ่มช่วงอ่านรอบถัดไป" และมีแถบมินิเวลาที่ก้นจอทุกหน้าขณะเวลาเดินอยู่
- เลือกวิชาและหัวข้อย่อย 2 ที่กำลังอ่านได้ (ไม่บังคับ) ระบบบันทึกเวลาอ่านสะสม แสดงที่แท็บจับเวลา หน้าหัวข้อ และหน้าภาพรวม เวลาที่เกินหลังหมดเวลาไม่ถูกนับ และการลบวิชา/หัวข้อจะลบเวลาที่บันทึกไว้ของสิ่งนั้นด้วย
- โหมดมืด สำรอง/นำเข้าข้อมูลเป็น JSON (รวมเวลาอ่านและค่าตั้ง Pomodoro)

## หน้าตั้งต้น
พิมพ์หนึ่งบรรทัดต่อหนึ่งหัวข้อย่อย ขึ้นต้นบรรทัดด้วย `-` หรือเว้นวรรค 2 ช่องเพื่อใส่หัวข้อย่อย 2 ไว้ข้างใต้

## การเก็บข้อมูล
ข้อมูลเก็บใน localStorage ของเบราว์เซอร์ (คีย์ `study-tracker-v2`) ควรกดสำรองข้อมูลเป็นระยะ ข้อมูลของเวอร์ชันเก่า (`study-tracker-v1`, โครงสร้างวิชา → หัวข้อ) ไม่ถูกนำมาใช้และไม่ถูกลบ ไฟล์สำรองเวอร์ชันเก่านำเข้าไม่ได้
